# 🛒 Supermarket Billing System

A simple **Java-based Supermarket Billing System** that manages customer queues, calculates bills, supports undo operations, and stores billing history using file handling.

## ✨ Features

- Add customers to the billing queue.
- Serve customers in FIFO order.
- Calculate bills using predefined product prices.
- Undo the last scanned item.
- View waiting customers.
- Save and load bill history using `bills.txt`.
- Input validation and exception handling.

## 🛠️ Technologies Used

- Java
- Queue (FIFO)
- HashMap
- Stack (LIFO)
- ArrayList
- File Handling
